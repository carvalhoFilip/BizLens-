# BizLens

> Simule a viabilidade do seu negócio antes de abrir as portas.

O **BizLens** é uma plataforma web de simulação e diagnóstico financeiro para pequenos negócios no Brasil. O empreendedor informa dados do modelo — nicho, preços, custos, operação e contexto regional — e recebe uma análise completa com faturamento estimado, ponto de equilíbrio, riscos e recomendações práticas para tomar a decisão certa.

---

## O problema

A maioria dos pequenos negócios no Brasil abre sem nenhum diagnóstico financeiro real. Planilhas genéricas não consideram o nicho, a região ou o modelo operacional. Consultores custam caro. O resultado: 60% fecham antes de 5 anos.

## A solução

O BizLens transforma dados simples do usuário em um relatório estruturado de viabilidade — em minutos, sem precisar de planilha ou contador.

**O que o sistema entrega:**

- Estimativa de faturamento por nicho e contexto regional
- Cálculo de custos fixos, variáveis e CAPEX
- Ponto de equilíbrio e payback estimado
- Score de viabilidade com explicação
- Riscos identificados e recomendações práticas
- Relatório em camadas (plano free e planos pagos)

---

## Stack

- **Frontend:** Next.js 14, TypeScript, Tailwind CSS
- **Backend:** Next.js API Routes
- **Banco de dados:** PostgreSQL (via Prisma)
- **Autenticação:** NextAuth.js
- **Pagamentos:** Stripe
- **Deploy:** Vercel
